# ForensixEML

Installation steps:
Ensure you have `Python 3.12`.
In VS Code, in the folder to the git repo, open terminal and run the commands sequentially. 
```Powershell
 py -3.12 -m venv .venv
 Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
 .\.venv\Scripts\activate
 python install.py
 ```
